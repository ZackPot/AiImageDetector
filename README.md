AiImageDetector
Detecting AI-generated images using PCA and FFT

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

AiImageDetector is a Python library that employs a logistic regression model, enhanced with Principal Component Analysis (PCA), to classify images. It specifically aims to differentiate between images generated by Stable Diffusion and real photographs by analyzing their Fast Fourier Transforms (FFT). This tool is designed for researchers and developers working on digital forensics, content authenticity verification, or understanding the characteristics of AI-generated imagery.

*   **Fast Fourier Transform (FFT) Analysis:** Extracts frequency domain features from images.
*   **Principal Component Analysis (PCA):** Reduces the dimensionality of the FFT features for efficient processing.
*   **Logistic Regression Classifier:** A robust model trained to distinguish between AI-generated and real images.
*   **Pipeline Integration:** Seamlessly combines FFT, PCA, and classification into a cohesive workflow.
*   **Python-based:** Easy to integrate into existing Python projects.
*   **Visualizations**: Has a SHAP feature chart and a matplotlib graph showing the dominat feature's frequencies.

```bash
git clone https://github.com/ZackPot/AiImageDetector/new/main?filename=README.md
cd AiImageDetector
python3 test.py
```

Configuration for AiImageDetector is handled internally. The pre-trained logistic regression model and PCA components are loaded by default.
